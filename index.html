Antify

An ultra-lightweight, zero-bloat Windows floating desktop day widget powered by pure Win32 API.

Download Package (.ZIP)

Windows SmartScreen Note

Because this app is a custom-compiled, unsigned native C executable, Windows Defender may initially display a warning dialog. Rest assured, the application contains zero tracking or background bloat. Simply click More Info and select Run anyway to launch it.

Deployment Steps

01

Extract the Bundle

Download and extract the Antify.zip archive directly into a dedicated folder on your local drive.

02

Verify Folder Layout

Ensure the DayWidget.exe program file remains alongside the pre-configured Font/ subdirectory containing your typography files.

03

Run and Float

Double-click the executable to launch it contextually over your desktop layer. Drag to position anywhere; right-click to toggle persistent click-through parameters.
